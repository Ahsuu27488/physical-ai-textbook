A robot without perception is a very expensive remote-control car. Perception is the whole pipeline that turns raw numbers from sensors, such as pixel intensities, laser ranges and gyro rates, into things a robot can act on: "that is a cup, 40 centimetres ahead", "I am in the kitchen, facing the door". It has two halves. Seeing means extracting meaning from a single moment of sensor data. Estimating means combining many noisy moments into one belief about the world and about the robot itself.

This module walks through both halves in the order you will meet them in practice. You will start with the camera model and OpenCV, move to depth cameras, point clouds and lidar, then use pretrained deep networks for detection and segmentation. After that comes the mathematical heart of robotics, Bayesian state estimation and the Kalman filter, and finally SLAM, where a robot builds a map and locates itself in it at the same time.

## By the end of this module you can…

- Project 3D points into an image with the pinhole model and calibrate a real camera.
- Process images and point clouds with OpenCV and Open3D.
- Run pretrained detection and segmentation models and read their outputs correctly.
- Implement a Kalman filter in NumPy and configure `robot_localization` for a real robot.
- Build a map with `slam_toolbox` and localize in it with AMCL.

## Module project

Make your simulated robot from the previous module perceive. Run `slam_toolbox` in your Gazebo world, drive the robot around with the keyboard until the map closes, save it with `map_saver_cli`, then restart with AMCL and watch the robot re-localize from a bad initial guess. Add an `ekf_node` fusing wheel odometry and IMU. Your deliverable is a short screen recording and a bag file showing the map building up and the localization converging.
