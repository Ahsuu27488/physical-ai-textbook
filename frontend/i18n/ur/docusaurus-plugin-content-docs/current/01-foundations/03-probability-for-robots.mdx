فاصلے کا ایک سینسر کہتا ہے کہ دیوار 2.10 میٹر دور ہے۔ دوسرا سینسر کہتا ہے 1.96 میٹر۔ کوئی بھی جھوٹ نہیں بول رہا: دونوں میں شور (noise) ہے۔ آپ کس پر یقین کریں گے، اور روبوٹ کو کیا نتیجہ اخذ کرنا چاہیے؟ روبوٹکس میں ہر سینسر کچھ حد تک غلط ہوتا ہے، اس لیے روبوٹ کو یہ اندازہ لگانا ہوتا ہے کہ وہ کتنا غلط ہے، اور شواہد کو معقول طریقے سے جوڑنا ہوتا ہے۔ یہی منطق احتمال (probability) ہے، اور یہ سبق اسے ایسے کوڈ میں بدلتا ہے جسے آپ چلا سکتے ہیں۔

<Objectives>

- ایک شور زدہ پیمائش کو اوسط (mean) اور تغیر (variance) کے ساتھ ایک بے ترتیب متغیر (random variable) کے طور پر بیان کریں۔
- گاؤسیئن سینسر نوائز کا سمیولیشن کریں اور دکھائیں کہ اوسط نکالنے سے یہ N کے جذر (square root) سے کم ہو جاتا ہے۔
- دو گاؤسیئن پیمائشوں کو ایک بہتر تخمینے میں یکجا (fuse) کریں۔
- ایک الگ پتہ لگانے والے (discrete detector) اور راہداری میں خود کو لوکلائز کرنے والے روبوٹ پر بیز کا اصول لاگو کریں۔
- کوویریئنس میٹرکس (covariance matrix) کو پڑھیں۔

</Objectives>

## شور، اور اس کے بارے میں بات کرنے کا ایک طریقہ

ایک رینج سینسر کو بالکل 2.00 میٹر دور موجود دیوار پر نشانہ بنائیں اور سو بار اس کی ریڈنگ لیں۔ آپ کو ہر بار 2.00 نہیں ملے گا۔ آپ کو حقیقت کے گرد جمع شدہ اقدار کا ایک بادل ملے گا۔ ہم اسے ایک <Term def="ایک بے ترتیب متغیر (random variable) ایک ایسی مقدار ہے جس کی قدر ہر پیمائش کے ساتھ بدلتی ہے، اور اسے احتمال کی تقسیم (probability distribution) کے ذریعے بیان کیا جاتا ہے۔">random variable</Term> کے ذریعے بیان کرتے ہیں۔

دو اعداد اس کا خلاصہ کرتے ہیں:

- **اوسط** (mean) $\mu$ مرکز ہے: اوسط قدر۔
- **تغیر** (variance) $\sigma^2$ پھیلاؤ ہے، اور اس کا مربع جزر $\sigma$ **معیاری انحراف** (standard deviation) ہے، جس کی اکائیاں وہی ہوتی ہیں جو پیمائش کی ہوتی ہیں۔

سینسر کے شور کے لیے سب سے عام ماڈل **گاؤسیئن** (نارمل) تقسیم ہے، جسے $\mathcal N(\mu,\sigma^2)$ لکھا جاتا ہے، اور اس کی کثافت (density) یہ ہے:

$$
p(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).
$$

ایک گاؤسیئن کے لیے، تقریباً 68% ریڈنگز اوسط کے ایک $\sigma$ کے اندر، 95% دو کے اندر، اور 99.7% تین کے اندر آتی ہیں۔ گاؤسیئن ہی کیوں؟ غلطی کے بہت سے چھوٹے آزاد ذرائع جمع ہوتے ہیں، اور بہت سے چھوٹے بے ترتیب اثرات کا مجموعہ گاؤسیئن کی طرف جاتا ہے۔ یہ ریاضیاتی طور پر بھی آسان ہے، جیسا کہ آپ فیوژن کے مرحلے میں دیکھیں گے۔

```python title="noise.py"
import numpy as np

rng = np.random.default_rng(42)          # fixed seed for repeatable results
true_range = 2.00                        # metres
sigma = 0.05                             # sensor standard deviation, metres

readings = true_range + rng.normal(0.0, sigma, size=100)
print(readings.mean())                   # close to 2.00
print(readings.std(ddof=1))
