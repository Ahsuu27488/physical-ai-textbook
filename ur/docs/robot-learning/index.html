Robot learning

Hand-written planners and controllers are wonderful when you can describe the problem precisely. Folding a towel, picking an object you have never seen, or walking over rubble is much harder to write rules for. Robot learning replaces some of those rules with a model trained on data: either demonstrations from a person, or the robot's own trial and error.

This module goes from a small neural-network refresher to the ideas behind today's robot policies. You will train a network on toy data, learn why copying an expert is trickier than it sounds, run reinforcement learning on a classic control task, see how thousands of simulated robots are trained in parallel, and look at the datasets that make large robot models possible.

By the end of this module you can…​

  • Train and evaluate a small PyTorch model and spot overfitting.
  • Explain behavior cloning, covariate shift and DAgger, and describe how ACT and Diffusion Policy produce actions.
  • Define an MDP, returns and value functions, and run a policy-gradient agent on CartPole.
  • Describe how massively parallel simulation, reward design, domain randomization and curricula fit together in Isaac Lab.
  • Judge a robot dataset for quality, coverage and embodiment, and explain why cross-embodiment data matters.

Module project​

Teach something small. Pick a task in a simulator (CartPole is fine to start, a simulated arm reaching task is better) and solve it two ways: once with imitation from a scripted expert, once with reinforcement learning. Compare how much data or experience each needed, how well each handled starting positions it had not seen, and what broke first. A one-page write-up with two learning curves is the deliverable.
